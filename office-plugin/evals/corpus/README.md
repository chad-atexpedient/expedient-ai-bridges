# Corpus policy

Nothing in this directory is committed except this file.

Real eval workbooks - especially any derived from licensed, proprietary, or
customer material - belong in a private corpus outside this repository.

Before using any workbook as a seed, scrub it:

- hidden sheets and very-hidden sheets
- personal metadata and custom document properties
- comments and tutoring notes
- external workbook links (these have been observed pointing directly at
  answer-key files)
- cached formula values
- VBA projects
- non-builtin defined names belonging to validation machinery

Assume every one of these leaks either the answer or confidential data until
proven otherwise.
