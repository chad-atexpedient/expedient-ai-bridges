WHY THE BRIDGE EXISTS

Compatibility is infrastructure.

Not another chat app. A translation, resilience, and policy boundary between opinionated clients and the endpoint your organization selects.

01

Protocol transcoding

Responses, Chat Completions, Anthropic Messages, tools, images, thinking blocks, and streams cross dialects.

02

Model aliasing

Stable client names map to configurable enterprise model slots while preserving tool behavior.

03

Stream resilience

Connect, idle, and total timeouts combine with bounded retries and controlled fallback.

04

Credential isolation

A local placeholder keeps the upstream credential in protected per-user configuration.

05

Capacity controls

Request limits, concurrency ceilings, and backpressure protect the local gateway.

06

Release evidence

CI candidates include manifests, checksums, SPDX SBOMs, and hash-pinned runtimes.

TWO DIALECTS IN · ONE UPSTREAM OUT

Clients keep speaking native.

Accept

OpenAI/Codex enters on 4001. Anthropic/Claude enters on 4002.

Normalize

Messages, tools, models, token controls, and stream semantics become one internal contract.

Route

The request travels to the configured OpenAI-compatible endpoint with protected credentials.

Translate back

The response returns in the payload and event format expected by the calling client.
